# Personal Workday Tracker (متابع أيام العمل الشخصي)

A standalone, single-file offline web application (`index.html`) designed to track personal workdays and keep accurate records without requiring internet access or a backend server.

## Features

- **100% Offline & Serverless**: Runs directly inside any desktop or mobile browser.
- **RTL Arabic Support**: Built with Right-to-Left (RTL) Arabic layout and typography.
- **Mobile Responsive**: Optimised mobile design with dynamic view switching.
- **Data Persistence**: Uses browser `localStorage` to save and persist workday records indefinitely.
- **Summary & Analytics**: Includes total count summary and chronological sorting (newest to oldest).
- **Interactive Feedback**: Instant toast notifications on save/delete actions and deletion confirmation safeguards.

## How to Run

Simply open `index.html` in any modern web browser on your phone or desktop computer. No installation or setup required.
